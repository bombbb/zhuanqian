# Update 2026-02-14

## Summary
- Enforced a hard max order amount of `300 USDT` (even after `minNotional` adjustments).
- Added a buy-order expiry (`maxBuyOpenSeconds`, default `120s`) to prevent long-lived BUY hangs.
- Added a recent-price band cap for `maxBuyPrice` (percentile-based) plus a hard ceiling.
- Fixed profit check to use actual spread vs `minProfitTick`.
- Added a manual Gradle task to update and verify MongoDB config without `mongosh`.
- Stabilized tests and excluded integration tests by default.

## Key Config Values (Recommended)
- `maxBuyAmountUsdt = 300`
- `maxBuyPrice = 1.0004`
- `maxBuyPriceCeiling = 1.0004`
- `maxBuyOpenSeconds = 120`
- `enableRecentPriceBandAdjust = true`
- `recentPriceLookbackDays = 30`
- `recentPricePercentile = 0.85`
- `recentPriceSafetyMargin = 0.00005`

## Behavior Changes
- **Max order cap**: If `minNotional` forces quantity up, order is capped to `maxBuyAmountUsdt`. If the cap breaks `minNotional`, the order is skipped.
- **Buy expiry**: BUY orders older than `maxBuyOpenSeconds` are canceled to release funds and order slots.
- **Dynamic max buy price**: Uses recent spread stats to calculate a percentile price, applies safety margin, then applies the hard ceiling.
- **Profit check**: Uses `bestAsk - bestBid` compared to `minProfitTick` instead of a no-op check.

## MongoDB Update (No `mongosh` required)
Run this to update and verify MongoDB config:
```bash
./gradlew updateMongoConfig --rerun-tasks
```
It updates `strategy_config` (SIMULATION preferred; otherwise enabled config) and prints the final values.

## Tests
Default unit tests (integration excluded):
```bash
./gradlew test
```
